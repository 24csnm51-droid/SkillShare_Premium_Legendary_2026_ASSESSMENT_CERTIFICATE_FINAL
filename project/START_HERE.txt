SKILLSHARE PREMIUM FINAL — 2026 EDITION

SETUP
-----
1) Extract the ZIP and open the project folder in VS Code.
2) Terminal:
   cd project
   pip install -r requirements.txt
   python app.py
3) Open: http://127.0.0.1:5000

OTP DEMO
--------
If real Fast2SMS credentials are not configured, the project creates a DEMO OTP
and prints it in the Flask terminal. It expires automatically. Correct OTP is
required before a learner account is created.

The initial admin mobile is 9876543210. Replace it from Admin > Security,
then verify it with the demo OTP before using OTP-protected password changes.
